## pips計算ツールでできること

pips計算ツールでは、エントリー価格と比較価格の差から、値幅をpipsまたはpointsで確認できます。

主に以下のような場面で使えます。

- エントリー価格からストップロス価格までの損切り幅を確認したいとき
- エントリー価格から利確価格までの利確幅を確認したいとき
- 決済後に実際の値幅を記録したいとき
- ロット計算やリスクリワード計算に使うpipsを確認したいとき
- トレード日誌に損切り幅や利確幅を記録したいとき

<CalloutBox variant="info" title="pips計算ツールは計算補助ツールです">
pips計算ツールは、入力された価格差から値幅を確認するための計算補助ツールです。エントリーの可否や相場の方向性を判断するものではありません。
</CalloutBox>

---

## 入力項目の意味

pips計算ツールでは、以下の項目を入力します。

| 入力項目 | 内容 | 入力例 |
|----------|------|--------|
| 通貨ペア・銘柄 | 値幅を確認したい銘柄 | USDJPY |
| 計算タイプ | 決済価格・ストップロス価格・利確価格のどれと比較するか | ストップロス価格で計算 |
| 取引方向 | 買い・売り | 買い |
| エントリー価格 | 取引に入る価格 | 150.000 |
| 比較価格 | 決済価格・ストップロス価格・利確価格 | 149.750 |

---

## 基本的な使い方

pips計算ツールは、次の流れで使います。

1. 通貨ペア・銘柄を選ぶ
2. 計算タイプを選ぶ（損切り幅・利確幅・決済後の確認など）
3. 買い・売りを選ぶ
4. エントリー価格を入力する
5. 比較価格（ストップロス価格・利確価格・決済価格）を入力する
6. 自動計算されたpipsまたはpointsを確認する
7. 利益方向・損失方向の判定を確認する
8. 必要に応じてロット計算やトレード日誌に活用する

<CalloutBox variant="tip" title="ストップロス価格を入れれば損切り幅を確認できます">
損切り幅が分からない場合でも、エントリー価格とストップロス価格を入力すれば、通貨ペア・銘柄に応じてpipsまたはpointsが自動計算されます。
</CalloutBox>

## USDJPYでの入力例

以下の条件で、pips計算ツールに入力する例を見てみます。

- 通貨ペア・銘柄：USDJPY
- 計算タイプ：エントリー価格とストップロス価格で計算
- 取引方向：買い
- エントリー価格：150.000
- ストップロス価格：149.750

```
価格差 = 150.000 − 149.750 = 0.250
```

USDJPYでは、1pips = 0.01として計算します。

```
値幅 = 0.250 ÷ 0.01 = 25pips
```

この場合、損切り幅は25pipsです。買い方向から見て、ストップロス価格は損失方向になります。

実際に価格差から値幅を確認したい場合は、[pips計算ツール](/tools/pips-calculator)を使って計算できます。

## EURUSDでの入力例

以下の条件で、EURUSDの値幅を確認します。

- 通貨ペア・銘柄：EURUSD
- 計算タイプ：エントリー価格とストップロス価格で計算
- 取引方向：買い
- エントリー価格：1.08500
- ストップロス価格：1.08250

```
価格差 = 1.08500 − 1.08250 = 0.00250
```

EURUSDでは、1pips = 0.0001として計算します。

```
値幅 = 0.00250 ÷ 0.0001 = 25pips
```

この場合も、損切り幅は25pipsです。価格のスケールが異なるだけで、計算の考え方はUSDJPYと同じです。

確認した損切り幅を使ってロット数を計算したい場合は、[ロット計算ツール](/tools/lot-calculator)を活用できます。

## XAUUSDやCFD銘柄を使う場合

XAUUSD、BTCUSD、JP225、US100、US500などのCFD銘柄では、FX通貨ペアのpipsではなく、pointsで値幅を表示します。

たとえば、XAUUSDでエントリー価格が2350.00、ストップロス価格が2345.00の場合、価格差は5.00です。

pointSizeを0.01として扱う場合、

```
値幅 = 5.00 ÷ 0.01 = 500points
```

計算したpointsは、[リスクリワード計算ツール](/tools/risk-reward-calculator)や[損益計算ツール](/tools/profit-loss-calculator)でも活用できます。

<CalloutBox variant="warning" title="CFD銘柄はブローカー仕様の確認が重要です">
CFD銘柄は、ブローカーによって最小変動単位や表示仕様が異なる場合があります。pips計算ツールの結果は参考値として確認し、実際の取引環境でも必ず確認してください。
</CalloutBox>

## 計算結果の見方

pips計算ツールの結果では、主に以下を確認します。

| 結果項目 | 意味 | 確認ポイント |
|----------|------|-------------|
| 値幅 | エントリー価格と比較価格の差 | 25pips・500pointsなど |
| 方向 | 利益方向・損失方向・同値 | 取引方向と価格差が合っているか |
| 通貨ペア・銘柄 | 選択した銘柄 | FXかCFDか |
| 取引方向 | 買い・売り | 判定が想定通りか |
| 計算単位 | pipSizeまたはpointSize | 1pips = 0.01など |

値幅そのものは価格差から計算されます。買い・売りの方向を選ぶことで、その値幅が利益方向なのか損失方向なのかも確認できます。

確認した値幅をトレード日誌に記録する場合は、[トレード日誌作成ツール](/tools/trade-journal-template)で損切り幅・利確幅とあわせて保存できます。
